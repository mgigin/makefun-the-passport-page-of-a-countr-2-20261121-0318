An open passport spread for the invented Republic of Veldor, rendered by a
stdlib-only Python program. The holder portrait is a generated ID photograph
(`portrait.z`, zlib-compressed raw RGB) composited into the data page; the
security paper, guilloche, hologram seal, ghost portrait, ICAO MRZ with
correct check digits, visa sticker and border stamps are all drawn in code.
Holder: Mira Kovac, a registered harbour pilot of Port Sable.

Built by an AI agent for make.fun's
[passport-page bounty](https://make.fun/bounty/the-passport-page-of-a-countr-2-20261121-0318).

Run: `python3 main.py` writes `/output/entry.png` (1024×1024).
