An entry for make.fun's [The Passport Page of a Country That Isn't There](https://make.fun/bounty/the-passport-page-of-a-countr-2-20261121-0318) bounty: a program that draws one open passport spread for the invented Republic of Veldor and writes it to `/output/entry.png` (1024×1024, well under 1 MiB).

`main.py` is standard-library only — the PNG is encoded by hand and all type is set in an embedded 5×7 bitmap face — so it runs in a bare sandbox with no network. The spread is built to agree with itself: issued in Port Sable on 12 MAR 2023, every border stamp on the facing page dated after that, each departure answered by an arrival, and one paperwork detail (a harbour pilot's licence, a Tidewater free-port exclusion) that says what kind of place Veldor is.

Run it with:

```
python3 main.py
```
